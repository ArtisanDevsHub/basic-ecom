# Contribution Guide

## Branch Naming Convention
story/dev-name/<story-name>
bugfix/dev-name/<short-description>

Examples:
- story/sadeq/user-auth
- bugfix/sadeq/product-api

---

## Pull Request Process
1. clone the repo or create a feature branch under your name
2. Commit code following these rules:
   - clear messages
   - small commits
3. Push branch
4. Open PR
5. Tag reviewer
6. Fix requested changes
7. Do not merge, once approved, admin will merge into main

---

## Coding Style
- Use async/await only
- Use try/catch in controllers
- Validate input
- perform proper testing
